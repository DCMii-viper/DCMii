# DCMii – F-16I Sufa Mod for DCS World

**Version 3.1** | Unofficial community project for **DCS World**

DCMii is a community project built on the **IDF Mods Project F-16I Sufa mod base**, with additional contributions from multiple creators. This repository provides project information, installation documentation, credits, license terms, and links to downloadable releases.

> **Important:** This project incorporates work by independent creators. All rights to third-party materials remain with their respective owners. Do not remove or misrepresent creator credits.

## Downloads

Download **DCMii F-16I Sufa V3.1** from the **Releases** section of this repository.

The release contains two separately packaged downloads:

| Package | Contents |
| --- | --- |
| **F-16 Sufa Main** | Main mod package |
| **F-16 Liveries** | Additional liveries package |

### If the download is split into multiple parts

Some releases contain numbered archive parts (for example, `DCMii_F16_Sufa_Main.7z.001`, `.002`, `.003`, etc.) due to GitHub's file-size limit.

1. Download **every part** of the package you want.
2. Place all parts in **the same folder**; do not rename them.
3. Install [7-Zip](https://www.7-zip.org/) if needed.
4. Right-click the **first part** (`.7z.001`) and extract it with 7-Zip. The remaining parts will be read automatically.
5. If extraction produces an original `.zip` file, extract that ZIP as well.
6. Follow the installation instructions below.

**Do not use GitHub's “Code → Download ZIP” button to download the actual mod.** That downloads repository contents, not the separate Release assets.

## Installation

1. Download the relevant release archives.
2. Read **[DCMii F-16 Sufa V3.1 – Installation Instructions](DCMii_F16_Sufa_V3.1_Install_Instructions.pdf)** before installing or replacing files.
3. Follow the steps in that PDF, including its prerequisites and folder locations.
4. Use **[V3.1 Changelog](DCMii_F16_Sufa_V3.1_Changelog.pdf)** to review the release changes.

Installation requirements and compatibility details are governed by the included installation instructions. Make a backup of any files that those instructions tell you to replace.
